# BUG-01 이름을 비우고 저장하면 안내 문구가 다름 (SC-13)

## 재현 순서 ##
1. 정리 결과 화면에서 식품 한 줄의 이름을 지운다.
2. 저장을 누른다.


## 기대 결과 ##
이름 칸이 표시되고 "이름을 입력해 주세요."가 보임. 저장되지 않음 (R-003)

## 실제 결과 ##
이름 칸 옆에 "값을 확인해 주세요.", 화면 아래에 "입력값을 확인해 주세요."가 보임. "이름을 입력해 주세요." 문구는 없음. 카드 0장.

## 증거 ##
--Network : POST /api/cards 요청시 보낸 값 {"name" : ""}
					돌아온 값 {"error" : ?}


# BUG-02 수량 오류 안내 문구가 다름 (SC-14)

## 재현 순서 ##
1. 정리 결과 화면에서 식품 한 줄의 수량 칸에 "많이"를 입력한다.
2. 수량을 비운 채 저장을 누른다.


## 기대 결과 ##
수량 칸이 표시되고 "수량은 숫자로 입력해 주세요."가 보임. 저장되지 않음 (R-003)

## 실제 결과 ##
"많이"를 입력하면 칸 값이 비어 있음. 저장하면 수량 칸 옆 "값을 확인해 주세요."와 "입력값을 확인해 주세요."가 보임. "수량은 숫자로 입력해 주세요." 문구는 없음. 카드 0장.

## 증거 ##
--Network : POST /api/cards 요청시 보낸 값 {"quantity" : null}
					돌아온 값 {"error" : ?}


# BUG-03 날짜가 아닌 기한을 넣고 저장해도 오류가 안 뜸 (SC-15)

## 재현 순서 ##
1. 정리 결과 화면에서 우유의 기한 칸에 "내일쯤"을 입력하고 저장을 누른다.
2. 저장 후 이동한 목록 화면을 본다.


## 기대 결과 ##
기한 칸이 표시되고 "기한은 날짜로 입력해 주세요. 예: 2026-10-25"가 보임. 저장되지 않음 (R-003)

## 실제 결과 ##
기한 칸에 입력한 값이 비어 있고, 저장하면 오류 문구 없이 목록으로 이동해 카드 5장이 보임(우유·양파는 "기한 없음").

## 증거 ##
--Network : POST /api/cards 요청시 보낸 값 {"due_date" : ?}
					돌아온 값 {"due_date" : ?}


# BUG-04 카드 수정에서 이름을 비우면 안내 문구가 다름 (SC-21)

## 재현 순서 ##
1. 목록에서 카드 하나의 수정을 연다.
2. 이름을 지우고 저장을 누른다.


## 기대 결과 ##
이름 칸이 표시되고 "이름을 입력해 주세요."가 보임. 목록의 카드는 수정 전 값 그대로 (R-003, D-005)

## 실제 결과 ##
이름 칸 옆 "값을 확인해 주세요."와 "입력값을 확인해 주세요."가 보임. "이름을 입력해 주세요." 문구는 없음. 취소 후 카드 이름은 수정 전 그대로.

## 증거 ##
--Network : PATCH /api/cards/{id} 요청시 보낸 값 {"name" : ""}
					돌아온 값 {"error" : ?}


# BUG-05 처음 열었을 때 빈 보드 안내가 짧음 (SC-38)

## 재현 순서 ##
1. 카드가 하나도 없는 새 브라우저(시크릿 창)로 앱을 연다.
2. 목록 화면을 본다.


## 기대 결과 ##
"남은 식품이 없습니다. 영수증 사진을 올려 식품을 추가해 보세요."가 보임 (R-008)

## 실제 결과 ##
"남은 식품이 없습니다."만 보임. "영수증 사진을 올려 식품을 추가해 보세요." 문장은 없음. (화면 위에 "사진 올리기" 버튼은 있음)

## 증거 ##
--Network : GET /api/cards 돌아온 값 {"items" : ?}


# BUG-06 모든 카드를 정리한 뒤 빈 보드 안내가 짧음 (SC-39)

## 재현 순서 ##
1. 목록의 카드를 하나씩 모두 정리한다.
2. 카드가 없어진 목록 화면을 본다.


## 기대 결과 ##
처음 열었을 때와 같은 빈 보드 안내가 보임 (R-009, R-008)

## 실제 결과 ##
카드 0장이고 "남은 식품이 없습니다."만 보임. "영수증 사진을 올려 식품을 추가해 보세요." 문장은 없음.

## 증거 ##
--Network : 마지막 카드 정리 PATCH /api/cards/{id} 요청시 보낸 값 {"status" : "archived"}
					돌아온 값 {"status" : ?}
					이어서 GET /api/cards 돌아온 값 {"items" : ?}
